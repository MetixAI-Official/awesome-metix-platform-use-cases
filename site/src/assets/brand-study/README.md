# Brand study fonts

Self-hosted, unmodified fonts from the official Google Fonts repository, downloaded
on 2026-09-28. Each font is distributed under its accompanying SIL Open Font License.

- Space Grotesk variable (300–700): https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Instrument Serif Regular: https://github.com/google/fonts/tree/main/ofl/instrumentserif
- Syne variable (400–800): https://github.com/google/fonts/tree/main/ofl/syne

These fonts are used by the brand design preview. The official Metix AI logo
remains its original SVG artwork.
